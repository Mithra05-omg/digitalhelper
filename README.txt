DIGITALHELPER PORTFOLIO: HOW TO PUT IT ONLINE (GitHub Pages, free)

You only need one file: index.html

STAY ANONYMOUS FIRST
Your GitHub username becomes part of the link (username.github.io/...).
If you want to stay anonymous, create a NEW GitHub account with a neutral name,
for example digitalhelper-my, and use a business email, not your real name.
Do not use your main account if it shows your real name.

STEP 1: Create the repository
1. Log in to GitHub.
2. Click New repository.
3. Name it: portfolio   (or any name you like)
4. Choose Public.
5. Click Create repository.

STEP 2: Upload the file
1. On the empty repository page, click "uploading an existing file".
2. Drag index.html into the box.
3. Click Commit changes.

STEP 3: Turn on GitHub Pages
1. Go to Settings > Pages.
2. Under "Build and deployment", set Source to "Deploy from a branch".
3. Choose branch: main, folder: / (root). Click Save.
4. Wait 1 to 2 minutes. Refresh the page.
5. Your link will appear at the top, like:
   https://your-username.github.io/portfolio/

STEP 4: Make the DM buttons work
1. Open index.html in the GitHub editor (click the file, then the pencil icon).
2. Find this line near the bottom:
   const THREADS_URL = "";
3. Put your Threads link between the quotes, for example:
   const THREADS_URL = "https://www.threads.net/@your_username";
4. Click Commit changes. Wait 1 minute, then refresh your link.

STEP 5: Use the link
Put the link in your Threads bio and in your quotations.

HOW TO EDIT TEXT LATER
Open index.html on GitHub, click the pencil icon, change the words
between the tags (for example change a project description), then Commit changes.

IMPORTANT
- The project previews use made-up businesses and sample data.
- Do not add real client names, internship screenshots, code or data.
- Do not add your name, phone number or photo if you want to stay anonymous.
